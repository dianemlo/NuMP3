# NuMP3
Creating a social media-like music desktop application.

# NuMP3 features:
- retro-styled music player
- caters to new music artists
- exploration of other users' music tastes and profiles

# A user will be able to:
- create and customize their profiles
- listen to songs and add songs to playlists
- create/generate playlists based off of genre/decade
- explore other people's profiles with dating app-like features

# How to run NuMP3
1. Open two VS Code terminals
2. In terminal 1: cd nump3-app, then npm install dependencies
3. In terminal 2: cd server_merged/merged/, then npm install dependencies
4. In terminal 2: node server.js
5. In terminal 1: npm run dev, then navigate/click on the localhost link provided
